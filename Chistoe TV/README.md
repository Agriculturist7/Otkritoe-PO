# Чистое ТВ

Android-приложение для просмотра прямого эфира телеканалов без рекламы (смартфон, планшет, Android TV).

В этой папке публикуются готовые сборки приложения для установки и самообновления:

- `ChistoeTV.apk` — последняя версия приложения;
- `version.json` — номер версии, ссылка на APK, контрольная сумма SHA-256, описание изменений.

Файлы появятся здесь после первой публикации сборки.

## Установка
1. Скачайте `ChistoeTV.apk` на устройство.
2. Разрешите установку из неизвестных источников.
3. Откройте файл и установите.

## Список каналов
- `ChistoeTV_channels.m3u` — единый плейлист (672 канала, у каналов по нескольку ссылок: первая основная, остальные запасные). Категории: Общие / Федеральные, Новостные, Кино и Сериалы, Развлекательные, Спортивные, Познавательные, Детские, Музыкальные, Региональные, Прочие, **С ограничениями** (геоблок, не круглосуточные, нужна подпись/Referer, иностранный язык).
- `ChistoeTV_channels_description.csv` — описание каждого канала.

Ссылка для приложения (Настройки → Загрузка плейлиста):
